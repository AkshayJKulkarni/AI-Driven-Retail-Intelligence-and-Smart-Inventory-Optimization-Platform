# AI-Driven Retail Intelligence and Smart Inventory Optimization Platform

## Overview

The AI-Driven Retail Intelligence and Smart Inventory Optimization Platform is an end-to-end Machine Learning project designed to help retailers forecast product demand, detect inventory risks, and optimize stock management decisions.

The system analyzes historical retail data and applies advanced feature engineering and predictive analytics to improve inventory planning and reduce understock or overstock situations.

---

## Problem Statement

Retail businesses often struggle with:

* Demand uncertainty
* Overstocking and understocking
* Inefficient inventory management
* Revenue loss due to poor forecasting

This project aims to solve these challenges using AI-driven demand forecasting and intelligent inventory optimization.

---

## Objectives

* Forecast future product demand
* Compare multiple Machine Learning and Deep Learning models
* Detect stock risks
* Recommend optimal inventory levels
* Provide actionable insights for retailers

## Feature Engineering

Key engineered features include:

* Previous Sales
* Rolling Sales Mean
* Rolling Sales Standard Deviation
* Inventory Coverage
* Inventory Gap
* Discount Competitor Ratio
* Order Fulfillment Ratio
* Rolling Sales Mean (7)
* Rolling Sales Max (7)

---

## Best Model Performance

| Model         | R² Score   |
| ------------- | ---------- |
| Random Forest | 0.6875     |
| XGBoost       | **0.6937** |
| CatBoost      | 0.6196     |
| LSTM          | -0.0018    |

The XGBoost model achieved the highest forecasting performance and was selected as the final prediction model.
